## 🎯 Objectifs pédagogiques

Ce TP marque la transition entre le développement exploratoire en notebook et les bonnes pratiques du génie logiciel industriel. Il pose les fondations de tous les outils MLOps qui seront vus par la suite (DVC, MLflow, Docker, Kubernetes).

| Objectif | Description |
|---|---|
| **A** | Migrer des notebooks vers des scripts Python de production dans VS Code |
| **B** | Structurer les dépendances via des environnements Conda isolés (`environment.yml`) |
| **C** | Mettre en place un versionnage Git propre + dépôt distant GitHub |
